# Weekly Hours & Earnings Calculator

A clean, lightweight calculator for freelancers and hourly workers to track weekly work hours and generate 1-page PDF timesheets.

🔗 **Live Demo:** [https://myhours-sand.vercel.app](https://myhours-sand.vercel.app)

---

## ✨ Features

- **Flexible Hourly Rate**: Set your custom rate ($/hr).
- **Weekly Schedule (Mon–Sun)**: Easily add or remove shift slots for any day.
- **Hour / Minute Toggle**: Log time seamlessly in hours (`hr`) or minutes (`min`).
- **Live Calculation**: Instant calculation of total hours, daily averages, and gross earnings.
- **1-Page PDF Export**: Generate a clean, 1-page PDF timesheet summary with automated date range filename (e.g. `5to11October.pdf`).
- **Light & Dark Theme**: Defaults to Light mode with smooth theme toggling.

---

## 🛠️ Tech Stack

- **Framework**: React + Vite
- **Styling**: Vanilla CSS (Custom Design System, Responsive)
- **Icons**: Lucide React
- **Effects**: Canvas Confetti

---

## 🚀 Getting Started

### 1. Clone & Install
```bash
git clone <your-repo-url>
cd myHours
npm install
```

### 2. Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Production Build
```bash
npm run build
```
